# Are You Sear-ious · Fire-kissed stuffed bell peppers

Complete React, TypeScript, Vite and Tailwind CSS 4 source for a three-burner
gas-grill recipe. Choose vegetarian, ground beef, ground chicken, or a split
vegetarian/beef batch. Ingredients, directions and temperature guidance update
together.

Use Node 22.13+ and run `npm ci`, `npm run dev`, and `npm run check`. For Vercel,
select Vite, build with `npm run build`, and publish `dist`. No environment
variables or Cloudflare runtime dependencies are needed.

The production build contains a self-contained HTML page with embedded local
Geist fonts. Keep its images, provenance, recipe, source and license files beside
it. No repository creation or deployment is performed by this package.
