# Validation scope — September 10, 2026

`npm run check` verifies types, lint, tests, production output, identical HTML/TXT,
inline code syntax, charcoal theme, embedded Geist, the recipe WebP, PNG/prompt
hashes, reference theme files and notices. Tests cover all four filling choices,
both pepper styles, 2–12 pepper scaling, US/metric units, Fahrenheit/Celsius,
filling-specific temperature guidance, split-batch separation, exactly three
burners including all eight combinations, saved settings, cook mode, print and
timer behavior.

Final packaging performs a clean install/rebuild, HTTP asset checks and ZIP-entry
hash verification. No physical cooking test, Vercel deployment, online
vulnerability audit or authenticated image-rights claim is made.
