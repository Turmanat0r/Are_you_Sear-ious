ARE YOU SEAR-IOUS — OFFLINE EDITION

1. Extract the ZIP completely using Extract All.
2. Open index.html in a modern browser, such as Chrome, Edge, Firefox, or Safari.
3. Keep the images folder beside index.html. Do not open the HTML from inside the ZIP.

No installation, web server, account, or internet connection is needed to use the app.
All code, styles, icons, and fonts are included inside index.html.
The images folder contains the 12 meal-specific WebP photos.

Included: beef/pork/poultry/fish recipes; cut and weight selection; ingredient scaling;
Fahrenheit/Celsius; pounds/kilograms; manual burner layout; ingredient checklists;
saved recipes; step-by-step cook mode and a check-in timer; cooking science; printing.

Printing: choose your cut and weight, then select Print. Your browser can also save it as a PDF.
Keep cook mode open for its timer; closing it resets the timer. Temperature determines doneness.

Browser storage: saved recipes and preferences are device/browser-local. Some browsers restrict
storage for local HTML files; the app still works, but saved settings may not survive closing it.
This file does not import preferences from the localhost or hosted edition.

The optional USDA reference links need internet when clicked. The burner diagram is a planner,
not a connection to a real grill. Follow your grill manufacturer's lighting instructions.

You can also upload index.html and the images folder to a static web host without changing the paths.
This ZIP is a standalone snapshot; later changes to the hosted app do not update this copy.
